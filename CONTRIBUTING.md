# Contributing

Phase 0 accepts public policy text and committed synthetic fixtures only.

- Do not scrape documents behind authentication or paywalls.
- Do not add circumvention, credential stuffing, or bypass logic.
- Do not enable network capture except on operator-owned devices with an explicit opt-in.
- Findings are observations, not legal conclusions or certifications.
- Do not commit live API keys. The LLM cache is a committed JSON file keyed by prompt hash.
